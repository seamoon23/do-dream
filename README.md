# Do Dream

아이디어를 해드림, 실행을 두드림.

Do Dream은 Idea Route Builder를 부제로 하는 로컬 우선 웹앱입니다.

아이디어, 참고 자료, 실행 단계, 프롬프트, 진행 판단, 진행 트리를 한곳에 모아 관리하는 로컬 우선 웹앱입니다. 서버, 로그인, 외부 AI API 없이 브라우저 IndexedDB에 데이터를 저장합니다.

## 실행 경로

프로젝트 폴더:

```powershell
cd "C:\Users\seamo\OneDrive\문서\APP_WEB"
```

개발 서버 실행:

```powershell

```

```powershell
npm run preview
```

Preview 접근 경로:

```text
http://127.0.0.1:4173
```

## 종료 방법

터미널에서 실행 중이면 터미널 창을 선택한 뒤:

```text
Ctrl + C
```

포트가 남아 있으면 PowerShell에서 PID를 찾아 종료합니다:

```powershell
Get-NetTCPConnection -LocalPort 5173,4173 -State Listen | Select-Object LocalPort,OwningProcess
Stop-Process -Id <PID> -Force
```

## 사용 흐름

1. `새 아이디어`로 아이디어 개요를 작성합니다.
2. `자료 모으기`에서 링크, 메모, 파일명/MIME/크기 같은 첨부 메타데이터를 등록합니다.
3. `프롬프트 준비`에서 단계별로 쓸 프롬프트 초안을 저장합니다.
4. `실행 계획`에서 단계, 완료 기준, 연결 자료와 프롬프트를 정리합니다.
5. `진행 판단`에서 현재 실행 가능성을 수동 점수로 기록합니다.
6. `흐름 보기`에서 단계, 이슈, 결정, 분기를 카드로 연결합니다.
7. `보관함`에서 JSON 백업 또는 Markdown 내보내기를 실행합니다.

## AI 검토 리포트 1차 흐름

이 MVP는 아직 외부 AI API를 직접 호출하지 않습니다. 대신 앱이 검토 요청서를 만들고, 사용자가 원하는 AI 대화창에 붙여넣은 뒤 결과를 다시 저장하는 방식입니다.

접근 경로:

```text
상단 탭 > 진행 판단 > AI 협업 리포트
```

사용 순서:

1. `요청서 복사`를 눌러 현재 아이디어, 자료, 단계, 프롬프트, 진행 트리를 포함한 검토 요청서를 복사합니다.
2. Codex, ChatGPT, Gemini, Claude 같은 별도 AI 대화창에 붙여넣고 답변을 받습니다.
3. 앱의 `AI 응답 붙여넣기`에 답변을 붙여넣습니다.
4. 자동 추출된 `결론`, `부족 자료`, `위험`, `다음 행동`을 확인하고 필요하면 수정합니다.
5. `AI 리포트 저장`을 눌러 대시보드와 Markdown Export에 반영합니다.
6. 저장된 리포트의 `후속 처리`에서 `리소스 후보`, `실행 단계`, `위험 카드`를 눌러 AI 피드백을 실제 보드 데이터로 전환합니다.

권장 답변 형식은 앱이 요청서에 함께 넣습니다. 핵심 heading은 `결론`, `부족 자료`, `위험`, `다음 행동`입니다.

## 백업과 복원

- `보관함 > 전체 JSON 백업`: IndexedDB에 저장된 모든 아이디어와 연결 데이터를 저장합니다.
- `보관함 > 선택 아이디어 Markdown`: 선택한 아이디어를 문서/AI 전달용 Markdown으로 내보냅니다.
- `보관함 > Markdown 복사`: 선택한 아이디어 Markdown을 클립보드에 복사해 AI 대화창에 바로 붙여넣습니다.
- `보관함 > JSON 복원/병합`: 백업 파일을 선택하면 데이터 건수를 확인한 뒤 `교체` 또는 `병합`을 선택합니다.
- `보관함` 상단에는 마지막 JSON 백업 시각이 표시됩니다.

주의: 브라우저 데이터를 삭제하거나 사이트 저장소를 초기화하면 IndexedDB 데이터도 사라질 수 있습니다. 중요한 작업 전에는 JSON 백업을 먼저 내려받는 것이 좋습니다. 새 백업은 v2 형식으로 저장되며, 기존 v1 백업도 계속 복원할 수 있습니다.

## MVP 범위

- 포함: 아이디어 CRUD, 자료/첨부 메타데이터, 검토 점수, 단계 설계, 프롬프트 관리, Markdown Export, JSON 백업/복원, React Flow 진행 트리.
- 제외: 서버 저장, 로그인, 외부 AI API 연동, 첨부 파일 본문 자동 분석.

## 다음 확장 후보

- AI 리포트 초안 생성: 현재 데이터와 Markdown Export를 기반으로 실행 가능성 리포트를 생성.
- 프롬프트 생성 보조: 도구별 프롬프트 스타일을 선택해 초안을 자동 제안.
- 백업 자동 알림: 일정 기간 백업하지 않았을 때 대시보드에서 안내.

## 빌드 메모

React, React Flow, Dexie, icon 번들은 Vite `manualChunks`로 분리되어 있습니다. React Flow가 큰 라이브러리라 단일 JS 청크 경고를 피하고, 이후 기능 확장 시 메인 앱 청크가 과도하게 커지지 않도록 하기 위한 설정입니다.
