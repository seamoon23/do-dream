# 08. 수동 테스트 체크리스트

## 아이디어 CRUD
- [ ] 제목 없이 저장 시 오류가 표시된다.
- [ ] 아이디어 생성 후 목록에 표시된다.
- [ ] 새로고침 후에도 아이디어가 유지된다.
- [ ] 상태 필터가 정상 동작한다.
- [ ] 태그 검색이 정상 동작한다.
- [ ] 삭제 전 확인창이 뜬다.

## 리소스
- [ ] 링크 리소스 등록 시 URL 검증이 동작한다.
- [ ] 메모 리소스가 저장된다.
- [ ] 파일 선택 시 파일명/타입/크기가 표시된다.
- [ ] 텍스트 파일 본문이 저장된다.
- [ ] 대용량 파일은 경고 또는 메타데이터만 저장된다.
- [ ] 리소스 상태를 `유효`, `부족`, `폐기`로 변경할 수 있다.

## 검토
- [ ] 점수는 1~5 범위만 입력된다.
- [ ] 평균이 자동 계산된다.
- [ ] 평균 4.0 이상이면 실행 추천으로 표시된다.
- [ ] 평균 3.0 이상 4.0 미만이면 보완 후 실행으로 표시된다.
- [ ] 평균 3.0 미만이면 보류 추천으로 표시된다.
- [ ] 부족 리소스 체크리스트가 저장된다.

## 단계 설계
- [ ] 기본 단계 자동 생성이 동작한다.
- [ ] 단계 추가/수정/삭제가 가능하다.
- [ ] 단계 순서가 유지된다.
- [ ] 단계별 완료 조건을 입력할 수 있다.
- [ ] 단계별 연결 리소스를 선택할 수 있다.

## 진행 트리
- [ ] 단계 기반 노드가 생성된다.
- [ ] 노드 위치 변경 후 새로고침해도 위치가 유지된다.
- [ ] 이슈 노드를 추가할 수 있다.
- [ ] 분기 엣지를 연결할 수 있다.
- [ ] 노드 삭제 시 연결 엣지가 정리된다.

## Export / Import
- [ ] 전체 JSON 백업 파일이 다운로드된다.
- [ ] 잘못된 JSON Import 시 기존 데이터가 유지된다.
- [ ] 정상 JSON Import 시 데이터가 복원된다.
- [ ] 아이디어 Markdown Export가 생성된다.
- [ ] Markdown에 아이디어, 리소스, 검토, 단계가 포함된다.

## 브라우저/환경
- [ ] Chrome/Edge에서 실행된다.
- [ ] 오프라인 상태에서도 기존 데이터 조회가 가능하다.
- [ ] IndexedDB 차단/오류 시 사용자 메시지가 표시된다.
