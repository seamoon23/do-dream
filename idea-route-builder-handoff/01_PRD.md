# 01. PRD — Idea Route Builder

## 1. 배경
아이디어는 계속 쌓이지만, 다음 문제가 반복된다.

- 아이디어가 흩어져서 다시 찾기 어렵다.
- 실행 가능한지 판단할 기준이 없다.
- 필요한 자료/소스/프롬프트/참고 링크가 어느 정도 모였는지 확인하기 어렵다.
- 코덱스, 클로드코드, 제미나이 등에 넘길 때 매번 설명을 다시 구성해야 한다.
- 진행 중 방향이 바뀌면 원래 계획과 수정 방향을 함께 보기 어렵다.

## 2. 목표
아이디어를 하나의 단위로 관리하고, 실행 가능성 검토 → 단계 설계 → 실행 프롬프트 → 이슈/분기 추적까지 이어지는 개인용 작업 유틸리티 웹앱을 만든다.

## 3. 핵심 사용자
- 혼자 여러 아이디어를 관리하는 개발자
- AI 코딩 도구에 작업을 넘기기 전 요구사항을 정리하려는 사용자
- 프로젝트 진행 중 분기/수정 방향을 추적하고 싶은 사용자

## 4. MVP 범위
### 포함
- 아이디어 등록/수정/삭제/검색
- 아이디어 상태 관리: `수집`, `검토중`, `실행가능`, `진행중`, `보류`, `완료`
- 리소스 등록: 링크, 메모, 파일 메타데이터, 텍스트 파일 본문
- 실행 가능성 검토 점수
- 단계별 실행 계획 생성/수정
- 프롬프트 템플릿 관리
- React Flow 기반 단계/분기 트리
- JSON 백업/복원
- Markdown 내보내기

### 제외
- 사용자 로그인
- 멀티 디바이스 동기화
- 외부 AI API 자동 호출
- PDF/Docx 자동 파싱
- 팀 협업
- 실시간 공동 편집

## 5. 성공 기준
- 사용자가 5분 안에 아이디어 하나를 등록하고 검토표를 작성할 수 있다.
- 아이디어 하나를 Markdown으로 내보내 코덱스에 넘길 수 있다.
- 단계별 작업과 프롬프트를 트리로 확인할 수 있다.
- 브라우저 새로고침 후에도 데이터가 유지된다.
- JSON 백업/복원이 가능하다.

## 6. 핵심 개념
### Idea
관리 대상이 되는 아이디어 또는 프로젝트 후보.

### Resource
아이디어를 실행하기 위해 필요한 근거 자료. 링크, 파일, 메모, 코드 스니펫, 참고 문서 등을 포함한다.

### Review
아이디어 실행 가능성 평가. 기술 난이도, 리소스 충분도, 수익성, 시간, 리스크를 점수화한다.

### Stage
실행 단위. 예: 조사, 요구사항 정리, 디자인, 구현, 테스트, 배포.

### Flow Node
진행 단계 또는 분기 지점. 이슈가 생기면 원래 계획과 수정 계획을 별도 노드로 분리한다.

### Prompt Template
코덱스/클로드/제미나이 등에 넘길 수 있는 재사용 프롬프트.
