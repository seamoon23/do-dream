# AGENTS.md — Idea Route Builder

## 역할
이 프로젝트는 아이디어 관리, 실행 가능성 검토, 단계 설계, 진행 분기 추적을 위한 로컬 우선 웹앱이다.  
사용자는 SI/웹 개발 실무자이며, 빠른 MVP와 실제 사용성을 우선한다.

## 구현 원칙
- 한국어 UI를 기본으로 한다.
- 오늘 안에 실행 가능한 MVP를 우선한다.
- 서버, 로그인, 결제, 클라우드 동기화는 1차 범위에서 제외한다.
- 데이터는 IndexedDB에 저장하고 JSON/Markdown 내보내기를 제공한다.
- 예외 처리와 빈 상태 UI를 반드시 구현한다.
- 복잡한 기능은 추상화만 만들고, 사용자가 직접 수정할 수 있는 템플릿 기반으로 구현한다.

## 코드 스타일
- TypeScript strict 기준을 지킨다.
- 도메인 타입은 `src/types/domain.ts`에 모은다.
- DB 접근은 `src/db/` 아래에 격리한다.
- 화면 컴포넌트는 `src/features/` 기준으로 나눈다.
- 비즈니스 로직은 컴포넌트 내부에 과도하게 넣지 않는다.
- 삭제/초기화/가져오기 기능은 confirm 또는 별도 확인 절차를 둔다.

## 금지/보류
- 백엔드 서버 구현 금지.
- 외부 AI API 연동 금지.
- Electron/Tauri 패키징은 Phase 2 이후로 보류.
- PDF/Docx 파싱은 MVP 이후로 보류. MVP에서는 파일명/요약/태그/체크리스트를 수동 관리한다.

## 우선순위
1. 아이디어 CRUD
2. 리소스/첨부 메타데이터 CRUD
3. 검토 점수/체크리스트
4. 단계 설계
5. React Flow 기반 분기 트리
6. JSON/Markdown Export/Import
