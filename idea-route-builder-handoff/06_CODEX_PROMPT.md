# 06. Codex 시작 프롬프트

아래 요구사항을 기준으로 로컬 우선 웹앱 MVP를 구현해줘.

## 프로젝트명
Idea Route Builder

## 목적
아이디어를 등록하고, 관련 자료/첨부/메모를 모은 뒤, 실행 가능성을 점수로 검토하고, 단계별 실행 절차와 프롬프트를 관리하는 개인용 유틸리티 웹앱을 만든다.

## 기술 스택
- Vite
- React
- TypeScript
- Tailwind CSS
- Dexie.js / IndexedDB
- React Flow
- lucide-react

## 구현 우선순위
1. 프로젝트 초기화 및 기본 레이아웃
2. 아이디어 CRUD
3. 리소스/첨부 메타데이터 관리
4. 검토 점수 입력 및 판정
5. 단계 설계
6. Markdown Export
7. React Flow 기반 진행 트리

## 핵심 UX
- 좌측에는 아이디어 목록/검색/필터
- 우측에는 선택된 아이디어 상세
- 상세는 탭 구조: 개요, 리소스, 검토, 단계 설계, 진행 트리, 프롬프트, 내보내기
- 모든 데이터는 브라우저 IndexedDB에 저장
- 새로고침 후에도 데이터 유지
- JSON 백업/복원 지원
- Markdown Export로 코덱스에 바로 넘길 수 있는 문서 생성

## 도메인 타입
`03_DATA_MODEL.md`의 TypeScript 타입을 기준으로 구현해줘.

## 파일 첨부 정책
MVP에서는 파일 자동 분석을 하지 않는다.
- 파일명, MIME 타입, 크기, 등록일 저장
- 사용자가 요약/태그/중요도 입력
- 텍스트 파일은 본문 저장 가능
- PDF/Docx는 자동 파싱하지 않고 메타데이터와 수동 요약만 관리

## 검토 점수
8개 항목을 1~5점으로 입력한다.
- 문제 명확성
- 사용자 가치
- 구현 난이도
- 리소스 충분도
- 기술 적합성
- 확장 가능성
- 수익/활용 가능성
- 리스크

평균 기준:
- 4.0 이상: 실행 추천
- 3.0 이상: 보완 후 실행
- 3.0 미만: 보류 추천

## 기본 단계 템플릿
1. 아이디어 정리
2. 요구사항 정의
3. 데이터 모델 설계
4. 화면 설계
5. MVP 구현
6. 테스트
7. 배포/패키징
8. 회고/개선

## 예외 처리
- 제목 공백 저장 금지
- 점수는 1~5 범위만 허용
- URL 형식 검증
- JSON Import 실패 시 기존 데이터 보존
- 삭제 전 확인
- Dexie 오류는 사용자에게 메시지 표시
- 빈 목록/빈 리소스/빈 단계 UI 제공

## 산출물
- 실행 가능한 React 앱
- 타입 안정성 있는 도메인 모델
- IndexedDB 저장/조회 구현
- 기본 샘플 데이터
- Markdown Export 기능
- 주요 기능 수동 테스트 체크리스트

## 구현 방식
먼저 전체 파일 구조를 제안한 뒤, 핵심 파일부터 생성해줘.
너무 큰 기능을 한 번에 만들지 말고 Phase 단위로 구현하고 각 Phase가 끝날 때 실행/검증 방법을 알려줘.
