# 05. 구현 계획

## Phase 0. 프로젝트 초기화

### 목표
로컬에서 실행 가능한 React TypeScript 앱 생성.

### 작업
- Vite React TS 프로젝트 생성
- Tailwind 설정
- 기본 레이아웃 구성
- 라우팅 없이 단일 페이지 상태 기반으로 시작
- 샘플 데이터 주입 버튼 추가

### 완료 조건
- `npm run dev`로 실행된다.
- 좌측 아이디어 목록과 우측 상세 영역이 보인다.

## Phase 1. 아이디어 CRUD

### 작업
- Idea 타입 정의
- Dexie DB 생성
- 아이디어 생성/수정/삭제
- 상태/태그/검색 필터
- 빈 상태 UI

### 예외 처리
- 제목 공백 저장 방지
- 삭제 전 confirm
- DB 오류 toast 표시
- 잘못된 priority 값 방지

### 완료 조건
- 새로고침 후 아이디어가 유지된다.

## Phase 2. 리소스/첨부 관리

### 작업
- Resource 타입 정의
- 링크/메모/파일 메타데이터 등록
- 텍스트 파일은 FileReader로 본문 저장
- PDF/이미지는 파일명/요약/태그만 저장
- 리소스 상태 변경

### 예외 처리
- 너무 큰 텍스트 파일 경고
- URL 형식 검증
- 지원하지 않는 파일은 메타데이터만 저장

### 완료 조건
- 아이디어별 리소스 목록이 유지된다.
- 리소스가 검토 화면에서 개수로 반영된다.

## Phase 3. 실행 가능성 검토

### 작업
- ReviewScore 타입 정의
- 8개 항목 1~5점 입력
- 평균/판정 자동 계산
- 부족 리소스 체크리스트 생성
- 검토 메모 저장

### 완료 조건
- 점수 저장 후 아이디어 카드에 평균 점수가 표시된다.

## Phase 4. 단계 설계

### 작업
- Stage 타입 정의
- 기본 단계 자동 생성
- 단계 추가/수정/삭제
- 단계 상태 변경
- 단계별 연결 리소스 선택

### 완료 조건
- 아이디어마다 단계 목록을 관리할 수 있다.

## Phase 5. 진행 트리

### 작업
- React Flow 설치/적용
- Stage 기반 노드 자동 생성
- 노드 추가/수정/삭제
- 엣지 추가/삭제
- 이슈 발생 시 분기 노드 생성

### 완료 조건
- 원래 방향과 수정 방향을 같은 화면에서 볼 수 있다.
- 노드 위치가 저장된다.

## Phase 6. 프롬프트 라이브러리

### 작업
- 기본 프롬프트 템플릿 생성
- 단계별 프롬프트 연결
- 변수 치환 미리보기
- 클립보드 복사

### 완료 조건
- 단계 상세에서 연결 프롬프트를 확인하고 복사할 수 있다.

## Phase 7. Export / Import

### 작업
- 전체 데이터 JSON 내보내기
- 전체 데이터 JSON 가져오기
- 아이디어 단위 Markdown 내보내기
- 가져오기 전 데이터 검증
- 가져오기 충돌 처리: 덮어쓰기/병합 선택

### 완료 조건
- 코덱스에 넘길 수 있는 Markdown 산출물이 생성된다.

## 오늘 MVP 추천 컷
시간이 부족하면 아래까지만 구현한다.

1. 아이디어 CRUD
2. 리소스 메타데이터
3. 검토 점수
4. 기본 단계 자동 생성
5. Markdown Export

React Flow 분기 트리는 가장 멋있지만 시간이 걸릴 수 있으므로, 오늘 안에 핵심 사용성을 만들려면 Phase 5는 마지막에 붙인다.
